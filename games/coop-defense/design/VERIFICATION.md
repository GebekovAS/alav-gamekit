# Проверка визуального редизайна

Наблюдаемый результат: восемь статичных экранов 600×440, оригинальные PNG вместо текстовых спрайтов, минимум надписей, читаемые роли объектов. A/B только листают альбом; боя, экономики и сети нет. Изменён только каталог игры; kit/, tool.py, examples/, AGENTS.md не редактировались.

## Воспроизведение

Pillow уже доступен в Python окружения Codex, хотя в системном Python 3.11 его нет:

```powershell
& C:/Users/gebek/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe games/coop-defense/design/make_art.py
python tool.py check coop-defense
python games/coop-defense/design/render.py
```

Генератор детерминирован (seed 49), использует 24 исходных цвета, проверяет размер фона. Pillow нужен только на ПК. main.py загружает все восемь изображений один раз; атласы используют src. render.py использует существующий tool.headless/tool.judge: восемь фиксированных состояний по 120 кадров, затем копирует PNG и текстовый дубль. PNG проверяются по сигнатуре и размеру. Временные захваты удаляются только внутри design/. Полный CLI check запускается отдельно и сохранён в final-check.log; статистика всех состояний — check.log.

## Критика и исправления

Все восемь PNG открыты в каждом из четырёх раундов, при исходном размере 600×440. Прежние версии заменены, ниже сохранена история решений.

1. **Первый раунд.** Маршрут уже читается, четыре врага различаются коробом, клином, куполом и выхлопами босса; башни — стволами, кристаллом и направляющими. Но контрастный клетчатый грунт спорит с силуэтами. Башня у верхней дороги пересекается с противником; игрок 2 накладывается на призрак резерва. Исправления: ближе оттенки грунта и меньше пятен, башни опущены от дороги, игрок 2 отведён вправо, A увеличена. Повторный рендер всех экранов.
2. **Второй раунд.** Трасса и резерв читаются лучше; на заставке и результатах нет мелкого текста. Облачко A всё ещё закрывает Клепатель, хотя перестало мешать врагам. Исправления: игрок 1 и облачко отведены левее башни, в полосе улучшения добавлены I → II. Повторный рендер всех экранов.
3. **Третий раунд.** Проверены все враги, все три типа башен, четыре игрока и номерные плашки. Перекрытия из прошлых раундов устранены. В меню остаются только цены, шкалы и переход уровня; в планах — головы, действия, цены и готовность. Остаток: близкие оттенки разных материалов можно объединить для более строгой палитры. Исправление: шесть близких оттенков объединены, осталось ровно 24 исходных цвета; полупрозрачность создаёт дополнительные смешанные оттенки. Повторный рендер всех экранов.
4. **Финальный раунд.** Все восемь PNG повторно открыты. Светлый край трассы отделяется от грунта, детали не теряются после сокращения палитры. Неподвижные объекты и декор не перекрывают HUD или угловые кнопки. Независимый просмотр восьми экранов принял макет на уровне статических снимков; бар резерва соответствует требованию, числовой таймер не требуется.
